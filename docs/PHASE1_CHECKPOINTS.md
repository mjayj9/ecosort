## 안전한 비교와 복구

현재 작업을 지우지 않고 **별도 폴더**에서 기준 버전을 열어 빌드한다. 아래 대상 폴더가 이미 있으면 다른 새 경로를 사용한다.

```powershell
cd C:\Users\admin\StudioProjects\ecosort_1
git worktree add --detach ..\ecosort-before-phase1 3889c0f
```

별도 폴더에는 Git에 넣지 않은 `local.properties`, 키스토어, 서버 환경설정, node_modules가 없을 수 있다. Android SDK 위치와 의존성을 해당 환경에서 설정한 뒤 빌드한다. NVIDIA 키를 Git에 넣어 복구하지 않는다.

단일 수정만 취소하려면 의존관계를 검토한 뒤 `git revert <커밋>`으로 취소 기록을 남긴다. `reset --hard`나 강제 푸시로 기존 작업을 지우지 않는다. ②~⑥은 신규 모듈을 순차로 추가한 개발 체크포인트이며, 완성된 앱/서버 쌍으로 즉시 배포할 수 있다고 가정하지 않는다.

**Git 복구와 Firebase 복구는 별개다.** 기준 APK(3889c0f)는 구계약, 최종 APK는 V2다. 소스를 되돌려도 이미 배포된 클라우드는 바뀌지 않는다. 실제 서비스 복구 시 선택한 커밋의 서버를 검토·배포하고 동일 계약의 APK를 설치해야 한다. 앱만 예전 것으로 바꾸면 업데이트 오류가 난다. 이 작업에서는 복구 시나리오 설명만 작성했으며 기준 버전으로 클라우드를 되돌리지 않았다.

기준 보존 커밋은 소스 복구 지점이다. Secret, Firebase 데이터, IAM, 외부 공급자 상태를 Git 커밋이 복원하지 않는다. Play Store는 변경하지 않았다.
