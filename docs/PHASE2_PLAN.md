# 2단계 · 등록 물품의 특징점 인식

기준 커밋 7b8268f. 사용자 승인: 2026-09-07. 보안·참조자료·인식기·앱 연결·검증을 별도 커밋으로 남긴다.

1. 보안: 현재 Firebase 키는 유지한다. 사용자 재지시에 따라 과거 프로젝트의 노출 키만 폐기한다. 실제 설정은 로컬 전용, 커밋/CI 비밀 검사 추가.
2. 입력: 사용자가 제공한 두유팩 6면을 기하 보정하여 참조면을 만든다. 위치·회전·크기가 바뀌는 합성 프레임과 Photo Picker의 실제 사진을 동일 인식기로 검사한다.
3. 인식: ORB 특징점 → Hamming 최근접 매칭 → 비율 검사 → RANSAC 호모그래피 → 충분한 점 수/분포/사각형 검증 → 연속 프레임 안정화. 인식기에 면 ID나 렌더러 정답 좌표를 전달하지 않는다.
4. 화면: 카메라·로그인 없이 시작 가능한 로컬 인식 실험실. 감지한 면의 사각형·특징점 표시, 이동/회전/크기 조절, 가림/빈 화면 반례, 실제 사진 선택. 사진 관찰과 물품 종류 제안 후 기존 서버 상태 확인 안내로 연결한다.
5. 검증: 합성 입력은 합성이라고 표시한다. 등록에 사용한 원본 사진의 재인식도 독립 평가로 포장하지 않는다. 다른 물품/빈 이미지 음성 사례, 시간·유실·재획득, 기존 V2 회귀, APK/키 검사를 기록한다.

현재 단계는 이 포장 디자인 한 종류의 참조 영상 인식이다. 일반 쓰레기 분류 모델 학습이나 내부 오염 측정이 아니다. 손 관절 모델처럼 의미 있는 3D 랜드마크를 학습했다고 주장하지 않는다. 6면 기반의 움직이는 평면 입력을 우선 구현하고, 완전한 3D 복원은 인식 검증에 필수가 아니므로 범위에 넣지 않는다.

OpenCV 공식 [특징점+호모그래피](https://docs.opencv.org/4.x/d1/de0/tutorial_py_feature_homography.html)와 [Android Maven 설치](https://docs.opencv.org/4.x/d5/df8/tutorial_dev_with_OCV_on_Android.html)를 참조한다. 사용자 예시는 [Make Me Cube Master](https://wooramsol.github.io/makemecubemaster/)이며 코드나 모델을 복제하지 않는다.
