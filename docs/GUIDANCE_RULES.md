# 공통 준비 안내의 근거와 범위

버전: 2026-09-07.1. 아래 공식 페이지의 본문을 2026-09-06에 확인하고 문장을 요약했다.

- [정책브리핑, 품목별 분리배출 방법, 2021-06-24](https://www.korea.kr/news/policyFocusView.do?newsId=148889163&pkgId=49500758): 내용물·잔여물, 부속품, 종이상자 및 품목 예외.
- [환경부 영상 설명, 2022](https://me.go.kr/m/mob/board/read.do?boardId=1525580&boardMasterId=53&menuId=58): 종이팩의 헹굼·건조와 금속캔 준비.
- [서울시 종이팩 전용수거함 사업, 2025](https://news.seoul.go.kr/env/archives/564359): 일반 폐지와 종이팩 수거의 구분 필요성. 서울시 사례를 전국에 적용하지 않는다.

본 버전은 지역별 수거함·요일·허용 여부 DB가 아니다. 따라서 모든 결과는 COMMON_PREPARATION이고 decision은 null이다. READY는 준비 안내가 가능하다는 뜻이다. 실제 재활용 가능 인증, 수거 가능 확정, 일반쓰레기 판정은 하지 않는다.

지원: 음료팩(일반팩/멸균팩은 사용자 표시 확인), 음료용 PET병, PET/PP/PE 식품 용기, 온전한 음료·식품용 금속캔/유리병, 코팅되지 않은 종이상자.
지원 밖: 약품·위험물·가스캔·깨진 물품·접시/도자기·복합재질 미확인 물품. 위험 검출은 모델 추정이며 완전한 안전성 검사가 아니다.

사진의 자유서술을 안내로 사용하지 않는다. 미개봉은 사용자 응답을 보존한다. 내부가 보이지 않으면 AI 내부 관찰을 만들지 않는다. 내용물/잔여물은 사용자 응답 출처로만 기록한다. 모름은 질문 재강제나 빈 용기 기본값으로 바꾸지 않는다.

검증: functions/test/policy.test.js의 반례는 입력/규칙 테스트이다. 실사진 정답률이나 AI 모델 성능 평가로 인용하면 안 된다.

2026-09-07 실사진 보완: 뚜껑이 닫힌 사용한 병을 AI가 미개봉으로 오인했다. 사용자 확인이 USED인 경우에도 사용 상태를 우선하되, 내용물/잔여물 질문과 위험·재질 검증은 유지한다. 최초 실패 보고서와 수정 후 보고서를 함께 보존한다.
